# Faster ways to stock signs

Status: **IDEA (recorded 2026-10-22)**. Not at launch.

The library lists every letter in every colorway as its own tile (359 then,
more since the decoration art), which is a long scroll.

- Group by set: one card per style and colorway (e.g. "Classic red alphabet"),
  opening to its letters, with "add the whole set".
- Filter by style, then color, then kind.
- Starter quantities: more E's and A's than Q's and Z's.
- Pairs with SIGN-PACKAGES.md.
